# Developer Environment Setup

Praelector is a local-first desktop application composed of:
1. **Tauri 2 (Rust)** desktop shell (`apps/desktop`)
2. **React 19 + TypeScript** front end (`apps/ui`)
3. **Python 3.12 FastAPI** sidecar engine (`engine/`)
4. **Provisioned TTS Worker** (`engine-tts/`)

---

## 1. Prerequisites

Ensure the following tools are installed on your machine:

| Tool | Version | Purpose | Installation |
|---|---|---|---|
| **Python** | `3.12.x` | Engine core & TTS runtime | [python.org](https://www.python.org/) or via `uv` |
| **uv** | `>=0.5.0` | Fast Python package management | `curl -LsSf https://astral.sh/uv/install.sh \| sh` or `winget install astral-sh.uv` |
| **Node.js** | `>=22.0.0` | Frontend build tooling | [nodejs.org](https://nodejs.org/) |
| **pnpm** | `>=9.0.0` | Monorepo package manager | `npm install -g pnpm` or `corepack enable` |
| **Rust** | `>=1.82.0` | Tauri 2 desktop shell | `rustup.rs` |
| **just** | `>=1.35.0` | Monorepo command runner | `cargo install just` or `winget install Casey.Just` |

### Optional External Tools
- **FFmpeg (`>=6.0`)**: Required for M4B multiplexing and audio loudness normalization.
- **Calibre (`>=7.0`)**: Optional; provides `ebook-convert` for PDF/MOBI/AZW3 conversion into EPUB.

---

## 2. Initial Setup

Clone the repository and install workspace dependencies:

```bash
# 1. Install Node workspace dependencies
pnpm install

# 2. Sync Python sidecar engine
uv sync --project engine

# 3. Sync Python TTS worker
uv sync --project engine-tts
```

---

## 3. Daily Development Workflow

Praelector uses `just` as a unified cross-platform task runner:

```bash
# Run all linters and code formatting checks
just lint

# Run all test suites (Python engine, TTS worker, UI vitest)
just test

# Start the full application in development mode (spawns engine + UI + desktop)
just dev

# Format all codebases (Ruff, ESLint, Cargo fmt)
just fmt

# Re-generate TypeScript interfaces from Python domain models
just codegen

# Static typechecking across Python (mypy) and UI (tsc)
just check
```

## 4. Environment Variables

| Variable | Description | Default |
|---|---|---|
| `PRAELECTOR_TOKEN` | Bearer token for API loopback authentication | Auto-generated by Tauri shell |
| `PRAELECTOR_PORT` | Port for FastAPI loopback engine | Ephemeral (`0`) |
| `PRAELECTOR_ENGINE_CMD` | Custom command to run engine binary in dev | `uv run --project engine praelector-engine` |
| `PRAELECTOR_LOG_LEVEL` | Engine log verbosity (`DEBUG`, `INFO`, `WARN`, `ERROR`) | `INFO` |

## 5. Security & Contribution Policies

- All committed source files must include the Apache-2.0 SPDX header:
  `// SPDX-License-Identifier: Apache-2.0` or `# SPDX-License-Identifier: Apache-2.0`.
- Python core (`engine/`) must remain 100% torch-free to maintain lightweight distribution (~120 MB).
- UI translations must maintain 100% key parity between English (`en`) and Polish (`pl`).
